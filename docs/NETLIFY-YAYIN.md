1. GitHub Releases'tan güncel ZIP'i indir ve aç.
2. Hızlı yayın: app.netlify.com/drop → açılan klasörü sürükle-bırak → site canlı.
3. Güncelleme yayını: Site deploy → aynı yolla yeni ZIP'i bırak (her sürümde sw cache adının arttığını kontrol et; kullanıcı tarafında eski önbellek bir hard refresh ile düşer).
4. Alan adı/form/ortam değişkeni gerekmez; Firebase/FCM kurulmadıysa uygulama çekirdeği bildirimler hariç tam çalışır.
