### G-02 · P1 · Tekrar merdiveni her tekrarda sıfırlanıyor (aralıklı tekrar → günlük tekrar)

**Belirti**

**Kök neden**
`site/index.html:1447` `const REVIEW_DAYS = [1, 3, 7, 14, 28];`
`site/index.html:1865-1880`:

```js
function scheduleReviews(topicKey) {

  ...

```

`markReviewed` (`1970`) ve `window.__kartTamamla` (`1936`) her tekrarda `scheduleReviews`'u çağırıyor. `reviewCount` **yalnız** unutma hızını yavaşlatmak için kullanılıyor (`1830`); merdiveni ilerletmek için hiçbir yerde kullanılmıyor. Sonuç: her tekrardan sonra "1. gün" basamağı yarına kurulur → ertesi gün yine due → tekrar günlüğe çöker.

**Yapılacak (öneri)**
1. `mem` içinde ilerleme tut: `mem.step` (0..`REVIEW_DAYS.length`). Şema göçü: `step == null` ise `Number(mem.reviewCount) || 0` kabul et (eski kayıtlar bozulmasın).
2. `scheduleReviews` yalnız **kalan** basamakları kursun:

```js
function scheduleReviews(topicKey) {
  const mem = state.memory[topicKey];
  if (!mem) return;
  const base = new Date(); base.setHours(0, 0, 0, 0);
  const dl = daysLeftToExam();
  const iv = idealReviewInterval();
  const adim = Math.min(REVIEW_DAYS.length, Math.max(0, Number(mem.step != null ? mem.step : mem.reviewCount) || 0));
  mem.schedule = {};
  REVIEW_DAYS.slice(adim).forEach(day => {
    let effDay = day;
    if (dl !== null && iv !== null && day > iv * 2) effDay = Math.max(1, Math.round(day * (iv / 14)));
    const dt = new Date(base); dt.setDate(dt.getDate() + effDay);
    mem.schedule[day] = toDayStr(dt);
  });
  saveState();
}
```

3. Tekrar kaydında `step`'i artır **ve** takvimi kur:
   - `window.__kartTamamla` (`1930-1955`) ve `markReviewed` (`1957-1974`): `mem.step = adim + 1;` sonra `scheduleReviews`.
4. **Merdiven bittiğinde** (`adim === REVIEW_DAYS.length`, `schedule` boş): karar gerekli.
   - Önerilen: `const REVIEW_BAKIM_GUN = 28;` — son basamaktan sonra `schedule = { 28: bugün+28 }` (bakım döngüsü). `nextReviewInfo` `null` dönerse Bilgi Bankası "Sıradaki: —" gösteriyor; bu istenmiyorsa bakım basamağı şart.

6. **Erken tekrar kararı (sahibi onayı gerekli, G-05 ile birlikte):**
   - **A (önerilen):** erken tekrar `step`'i **artırmaz**, yalnız `lastReview` yazar + takvimi mevcut basamaktan yeniden kurar. Böylece "her gün Erken Tekrar" takvimi öteleyemez.
   - **B:** erken tekrar `step`'i artırır (kullanıcı istediği zaman ilerler) — hızlı ama aralıklı tekrar disiplinini bozar.
   - Hangi seçilirse **açıkça yorumla** ve talimat dosyasının sonuna işaretle.

**Dokunma:** `memoryDecayRate` / `getMemoryStrength` formülü (doğru), `idealReviewInterval` (Cepeda, doğru), `EXAM_REGIMES`.

**Test (yeni):** `tests/tekrar-merdiveni.test.js`

```js
const KORUNAN_ALANLAR = [
  "onay_durumu", "son_kisa_kontrol", "son_kisa_kontrol_dogru", "son_kisa_kontrol_toplam",
  "son_kisa_kontrol_gecti", "precheck_due", "study_completed_at",

function rebuildAfterDeletion(s) {
  const yedek = {};
  Object.keys(s.bkt_state || {}).forEach(k => {
    const e = s.bkt_state[k] || {}, t = {};
    KORUNAN_ALANLAR.forEach(f => { if (e[f] !== undefined) t[f] = e[f]; });
```

```js
const fs = require("fs"), path = require("path");
```
